Snapshots

A snapshot saves the VM's disk as it is right now, in an instant. Take one before risky changes; roll back to undo everything since.

Backups

A backup is a full copy of the disk in a file. It survives even if the VM is deleted, and works while the VM runs.

Public IP pools

Blocks of public addresses from your datacenter or server provider. A VM created with "Public IP" gets the next free address, set inside the VM automatically (no DHCP), and can only use that address.
